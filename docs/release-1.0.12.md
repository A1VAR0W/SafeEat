# SafeEat 1.0.12

La verificación manual de productos por una cuenta ADMIN se realiza desde «Administración → Revisiones → Productos». El servidor bloquea la ruta normal de confirmación para ADMIN; la acción del panel comprueba que quien verifica no sea el autor y deja constancia en la auditoría. Las demás cuentas conservan las confirmaciones comunitarias.

Android usa `versionCode` 88 para actualizar desde la versión 1.0.11. La IPA de iOS mantiene el canal de SideStore/LiveContainer.

Validación de permisos y pruebas de API, compilaciones, publicación y enlaces se anotarán cuando terminen.
